# قصة الحلى — Sweet Story | قائمة رقمية تفاعلية (Digital QR Menu)

> **«من الدقيق تبدأ الحكاية»** — تجربة قائمة رقمية فاخرة مخصصة لمخبز عربي تقليدي يقدّم المعمول والبسبوسة.

---

## 🌟 مميزات المشروع

- **تجربة ترحيبية تفاعلية (Splash Screen):** فكرة مبتكرة لتفتيت قطعة المعمول بالضغط عليها قبل فتح القائمة، مع زر تجاوز سريع للمستعجلين وحفظ الجلسة (`sessionStorage`).
- **واجهات متجاوبة بالكامل (Responsive Design):** مصممة لتناسب كافة الشاشات (الهواتف الذكية، الأجهزة اللوحية، والشاشات الكبيرة) بنظام شبكي مرن وتوافق كامل مع الاتجاه من اليمين لليسار (`RTL`).
- **تصفح فوري وسريع (Single-Page App Router):** تنقل سلس بين الأقسام:
  - **الرئيسية (Home):** هيرو تفاعلي، بانر تعريفي، وبطاقات الدخول السريع للأصناف.
  - **المعمول (Maamoul):** تبويبات تصنيف (الكل / الكلاسيكي / المربعات) مع بطاقات منتجات بنسب متناسقة، وأسعار البوكسات (بوكس صغير / بوكس وسط / بوكس / بوكس كبير).
  - **البسبوسة والمعجنات (Basbousa & Pastries):** أصناف البسبوسة والمعجنات بصور عالية الجودة على أطباق، وتفاصيل الوزن والسعر.
  - **قصتنا (Story):** تعريف بالحِرفة وصناعة المعمول اليدوية التقليدية.
  - **تواصل معنا (Contact):** أزرار اتصال وواتساب مباشرة مع **رسالة طلب احترافية جاهزة**، العنوان (الخرج — حي النهضة، شارع الملك سلمان) مع رابط خرائط، وروابط التواصل الاجتماعي (واتساب · انستغرام · سناب شات).
- **نسخة قائمة مدمجة ذاتية التشغيل (`sweet-story-menu.html`):** ملف HTML واحد متكامل يضم كافة الصور والخطوط مدمجة بداخله بصيغة Base64، مما يتيح تشغيل المنيو بدون إنترنت تماماً أو إرساله كملف واحد عبر واتساب أو مسحه عبر كود QR.
- **تطبيق ويب تقدمي (PWA Ready):** دعم ملف `manifest.webmanifest` وأيقونة التطبيق للشاشات الرئيسية.

## 📸 رفع الصور (الطريقة الموثوقة)

رفع الصور من داخل المحادثة غير موثوق — المنصة تُعلن عن حفظ المرفقات في
`/home/user/uploads/` لكن هذا المسار لا يصل إلى بيئة العمل إطلاقاً.
لذلك بُنيت قناتان بديلتان، كلتاهما تطبّع الصورة (تقصّ على النسبة الصحيحة +
ضغط) ثم تعيد بناء `sweet-story-menu.html` تلقائياً:

### 1) صفحة الرفع في المتصفح (الأسهل)

```bash
# المنيو + صفحة الرفع في نفس الرابط (الأسهل):
python3 scripts/upload_server.py --port 8000 --static .
# أو صفحة الرفع وحدها:
python3 scripts/upload_server.py --port 8001
```

افتح رابط المنيو وأضف في آخره `/upload` — مثال:
`https://<sandbox-id>.e2b.app:8000/upload` — ثم اسحب الصورة وأفلتها، اختر
مكانها من القائمة، واضغط **رفع واستبدال**. الصورة تُحفظ في `images/`، والأصل
يبقى في `uploads/`، وتُعاد قائمة `sweet-story-menu.html` تلقائياً.

### 2) GitHub — القناة الموثوقة (موصى بها)

رفع المرفقات من المح DISCUSSION لا يصل، وروابط Cloud محجوبة، والمستودع هو
القناة الوحيدة التي تصل. من جوالك:

1. افتح `https://github.com/bossbaraka/alHalaStore/upload/main`
2. `choose files` ← اختر الصورة ← اكتب اسماً مثل `basbousa-qashta` ← Commit
3. اكتب لي «تم» ← أشغّل:

```bash
python3 scripts/sync_inbox.py            # يسحب الصور الجديدة ويطبّقها ويبني القائمة
python3 scripts/sync_inbox.py --list     # عرض ما ينتظر فقط
```

### 3) الماسح التلقائي (للصور التي تصل بأي مجلد)

```bash
python3 scripts/import_attachments.py --list              # عرض ما تم العثور عليه
python3 scripts/import_attachments.py                     # استيراد + بناء القائمة
python3 scripts/import_attachments.py img.jpg basbousa-02-qashta.jpg   # يدوي
```

يبحث في كل المسارات المحتملة (`/home/user/uploads`، `uploads/`، `/mnt/data`،
`/data`، `$ARENA_UPLOAD_DIR` …) ويطابق اسم الملف مع خانة المنيو المناسبة
(قشطة/halib/beehive/معجن/hero/sig/story/logo/maamoul-0X).

## 🚀 كيفية التشغيل والبناء

### 1. التشغيل المحلي:
يمكنك فتح ملف `index.html` أو `sweet-story-menu.html` مباشرة في أي متصفح.
أو عبر خادم محلي:
```bash
python -m http.server 8000
```
ثم فتح: `http://localhost:8000`

### 2. إعادة بناء النسخة المدمجة:
عند إضافة أي صور أو تعديل التصاميم، قم بتشغيل سكربت البناء:
```bash
python scripts/inline_images.py
```
سينتج ملف `sweet-story-menu.html` محدثاً بكافة الأصول والخطوط مدمجة بداخله.

## 🌐 النشر والاستضافة (Deployment)

المشروع مبني كـ Static Site بدون متطلبات سيرفر، وجاهز للرفع فوراً على:
- **GitHub Pages:** تفعيل النشر من إعدادات المستودع (Settings -> Pages -> Branch: main -> /root).
- **Vercel / Netlify / Cloudflare Pages:** ربط المستودع مباشرة وسينشر الموقع تلقائياً.
